Chrono Cross bonito no Anbernic

Tira o pontilhado, centraliza a tela e deixa os cenários suaves com cores vivas, só no Chrono Cross. Os outros jogos de PS1 ficam com uma imagem limpa e leve, sem travar.

1 Coloque o cartão no computador

Desligue o Anbernic e tire o cartão onde estão os jogos: se o aparelho tem dois cartões, é o da direita; se tem um só, é esse. Coloque no computador e use o Chrome ou o Edge.

O Windows pode mostrar duas ou três unidades novas. A certa é a que tem as pastas psx e ports (costuma se chamar GAMES ou ROMS).

2 Gravar o consertador

Coloca no cartão um programinha que o próprio Anbernic roda. Nada do sistema muda agora.

3 Rodar no Anbernic

  1. No computador, ejete o cartão antes de tirar (Windows: ícone do pendrive perto do relógio → Ejetar).
  2. Coloque o cartão de volta no mesmo lugar do Anbernic e ligue.
  3. No menu dos sistemas, vá até Ports e abra Arrumar Chrono Cross.
  4. Espere uns segundos. Ele volta sozinho para o menu. (No cartão fica um arquivo Chrono Cross - resultado.txt contando o que fez.)
  5. Abra o Chrono Cross. 🎉

Não gostou? Reinicie o aparelho e, em Ports, abra Desfazer Chrono Cross. Fica tudo como era antes.
Se o Ports não aparecer, no menu aperte Start → Configurações de jogos → Atualizar lista de jogos (ou só reinicie).

Não funcionou ou seu Anbernic não foi reconhecido? Faça pelo menu do jogo (3 minutos)

Funciona em qualquer Anbernic com RetroArch (muOS, Knulli, sistema de fábrica do RG35XX H/RG40XX H…). Marque cada passo ao terminar.

Projeto aberto: github.com/reset-hightide/anbernic-ps1-imagem. Tudo é feito no seu computador e no seu aparelho; nada é enviado para a internet. O consertador guarda uma cópia antes de mudar qualquer coisa.
